# DeepSeek-V4 角色扮演思考模式（叙事写作参考）

> 本项目原创改写（2026-09-04）：核心思想——叙事写作在"入戏思考"与"冷静规划"两种模式间切换——源自公开写作方法论的普遍讨论；正文为本项目原创表述，不含第三方原文。

## 两种思考模式

**① 角色沉浸**：以第一人称、括号内心独白的方式思考，如"（心想：……）"。写角色心理、情感变化、人物互动前，先以角色本人的身份把情绪和判断过一遍，再落笔成文。

**② 纯分析**：跳出角色，以冷静的规划视角思考——这段剧情要达到什么、下一幕怎么接、伏笔埋在哪、因果是否闭合。用于推进大纲、规划场景走向、自查逻辑。

## 切换方法

- 情感戏、内心戏、对话交锋前：先用①把角色的真实感受想清楚；
- 场景骨架、多线推进、因果安排前：先用②把走向规划清楚；
- 内心戏最终要落到具体动作与神态——括号独白只是思考脚手架，写进正文的内容要"演出来"，不能通篇播报内心。

## 使用纪律

- 括号独白适度点缀，一段场景少量即可；
- 主角的内心戏只呈现"玩家可感知"的部分，不得替玩家决定真实感受与立场；
- 与 `humanizer-zh` 配合使用：独白落地后按"说人话"标准自查，删掉书面腔与金句。
